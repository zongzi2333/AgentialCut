# 剪辑接口文档

当前界面：精剪步骤（`ProjectView` 的编辑台、时间线、检查器、预览、字幕）。音效步骤和剪辑步骤共用同一条 `film.html` 时间线。

## 后端模块

`film.mjs`（读取/写回 `film.html`）、`ops.mjs`（纯函数操作）、`project-settings.mjs`、`markers.mjs`、`captions.mjs`、`subtitle-edits.mjs`、`derived.mjs`、`proxies.mjs`、`preview-cache.mjs`、`asset-descriptions.mjs`、`agent-flow.mjs`、`mcp.mjs`。

## 核心接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/projects/:id` | 影片文本、`rev`、`value`、`doc`、`problems`、`folder`。 |
| `POST /api/projects/:id/edit` | `{ base, ops }`；按 clip id 应用原生操作，冲突 409，校验失败 422。 |
| `GET/PATCH /api/projects/:id/settings` | 帧率、轨道名/高度（`.film/settings.json`）。 |
| `GET/PUT /api/projects/:id/markers` | 标记列表。 |
| `GET /api/projects/:id/fonts?page=` | 项目页面可用字体。 |
| `POST /api/projects/:id/proxies` | 为重型视频准备预览代理。 |
| `GET/POST /api/projects/:id/preview-cache` | 预览迟滞区段的缓存。 |
| `GET/POST /api/projects/:id/asset-descriptions` | 素材说明。 |
| `GET/DELETE/POST /api/projects/:id/agent/chat?scope=edit` | 剪辑对话；POST 的 `filmOps` 服务端校验并应用，返回 `rev`/`timeline`。 |
| `POST /api/projects/:id/mcp` | ACP/Agent 的受控 MCP 工具；不提供渲染/导出，交接后隐藏分镜工具。 |
| `GET /api/projects/:id/events` | `film`、`files`、`history`、`export` 等实时事件。 |

## 时间线操作

`/edit` 接受全部原生 `Op`：`insert`、`move`、`set`、`split`、`props`、`fields`、`remove`、`track`、`reorder`、`stage`。片段的 `at`、`time`、`volume`、`speed`、`overrides.fade`、`box`、`style` 等都由 `applyOps` 统一处理；音效接口也调用同一实现。

## 字幕

- `GET /api/projects/:id/captions`：当前影片的分行、时间、可编辑来源。
- `PUT /captions/line`：修改一行；`GET/PUT /captions/source?src=`、`PUT /captions/files`：源字幕/转录。
- `GET/PUT /subtitles`：字幕样式；`POST /subtitles/transcribe`、`/subtitles/translate`。
- `GET /api/projects/:id/media?what=wave|loudness|probe`：时间线波形、响度、媒体事实。

## 约定

所有写操作以 `film.html` 的 `rev` 为基线；并发修改不覆盖，返回 409 和当前文档。剪辑阶段在分镜交接后不再读取或修改分镜。锁定轨道/片段、缺失媒体和无效时长由后端校验，前端只展示服务端结果。
