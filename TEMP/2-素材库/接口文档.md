# 素材库接口文档

当前界面：素材库步骤（`MediaLibraryStage`）和项目媒体面板。负责导入、文件夹、预览、探测、批量选择、篮子、语义索引、Saved 素材。

## 后端模块

`files.mjs`（导入/复制/链接/移动/回收站）、`derived.mjs`（ffprobe、poster、frame、wave、loudness）、`semantic-index.mjs`（旁车、向量库、任务）、`saved.mjs`（Saved 全局库）、`asset-descriptions.mjs`、`pages.mjs`。

## 项目文件

| 接口 | 用途 |
| --- | --- |
| `GET /api/projects/:id/files` | `{ files, folders, pages, made, links }`，含 `desc`。 |
| `PUT /api/projects/:id/files?path=` | 文件字节流式导入；返回 `{ path, unreadable? }`。 |
| `PATCH /api/projects/:id/files` | `{ from, to, check? }` 移动/改名；`check` 只看会破坏的页面链接。 |
| `DELETE /api/projects/:id/files?path=` | 移入回收站。 |
| `POST /api/projects/:id/files/bring` | 从本机复制/链接 `{ paths, into, mode }`；没有 paths 时打开系统选择器。 |
| `POST /api/projects/:id/files/relink`、`collect` | 重新指向链接、把链接内容收藏进项目。 |
| `POST /api/projects/:id/files/audio`、`still` | 从视频提取音轨、在指定毫秒取帧。 |
| `POST /api/projects/:id/folders` | 在 `assets/` 下建空文件夹。 |

## 媒体与语义

- `GET /api/projects/:id/media?what=probe|wave|loudness|poster|frame|file&path=`：媒体事实；`poster`/`frame` 返回 JPEG，`file` 下载。
- `GET/POST /api/projects/:id/asset-descriptions`：素材描述，POST `{ path, regenerate? }`。
- `GET /api/projects/:id/index`：当前项目向量库状态。
- `POST /api/projects/:id/index/jobs`：开始索引；`GET /api/index/jobs/:id?libraryId=`；`POST /api/index/jobs/:id/cancel?libraryId=`。
- `POST /api/projects/:id/index/search`：`{ query, mode:'frame'|'chunk', topK, libraryIds?, filters? }`。
- `PUT /index/stores`、`DELETE /index`、`PUT /index/root`：项目引用的 store、清索引、全局库位置。
- `GET /api/index`、`/index/health`、`/index/models`、`/index/libraries`、`/index/jobs...`：全局向量库与模型。

## Saved 与预览

`GET /api/saved/files`、`PUT/PATCH/DELETE /api/saved/files...`、`POST /api/saved/files/bring`、`GET /api/saved/media`；项目侧 `POST /api/projects/:id/saved`、`POST /saved/take`。文件预览走项目 `folder` 地址；缩略图和语义结果显示的 `thumbUrl` 走 `/api/index/thumb` 或 `/api/index/media`。

## 约定

路径均为项目相对 POSIX 路径；写接口拒绝 `..`、`.film/` 和非 assets 写入。导入仍使用临时文件，重名按 `name 2.ext` 处理，同一文件同字节可复用。语义旁车不可用时返回状态而不是假装有结果。
