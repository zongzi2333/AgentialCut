# 项目接口文档

当前界面：项目步骤（`ProjectStage`）和项目库。左侧显示当前影片事实，右侧复用 ProjectsLibrary 的搜索、排序、文件夹、封面、多选和新建。

## 后端模块

`server.mjs`、`projects.mjs`（项目目录与 `studio.json`）、`history.mjs`（版本）、`project-settings.mjs`（`.film/settings.json`）、`cover.mjs`、`watch.mjs`、`fetch-repo.mjs`。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/projects` | 项目列表（含 `missing`、`working`、封面时间）。 |
| `POST /api/projects` | `{ name }` 新建，或 `{ path, create? }` 打开/建立目录项目。 |
| `GET /api/projects/:id` | `{ project, folder, text, rev, value, doc, problems }`：影片和可加载的媒体目录。 |
| `PATCH /api/projects/:id` | 重命名；Agent 运行或导出进行中会拒绝。 |
| `DELETE /api/projects/:id` | 整个项目目录移入回收站。 |
| `POST /api/projects/:id/opened` | 记录最近打开的影片。 |
| `POST /api/projects/:id/reveal` | 在文件管理器中显示项目目录。 |
| `GET/PUT/PATCH/DELETE /api/projects/folders...` | 项目库文件夹：列表、新建、改名/移动、删除。 |
| `PUT /api/projects/:id/folder` | 把项目放入文件夹（`folderId: null` 为顶层）。 |
| `POST /api/projects/:id/locate` | 目录被移动后，用新绝对路径找回项目。 |
| `GET/POST /api/projects/fetch`、`GET/DELETE /api/projects/fetch/:id` | 从 GitHub 地址导入影片及进度。 |
| `PUT/POST/DELETE /api/projects/:id/cover` | 项目封面：设置图片/影片时刻、清除（读取封面用 `poster`）。 |
| `GET /api/projects/:id/poster` | 项目卡封面；没有自定封面时取影片中间帧，未就绪返回 503。 |
| `GET/PATCH /api/projects/:id/settings` | 帧率、轨道名、轨道高度。 |
| `GET /api/projects/:id/events` | WebSocket 事件：`project`、`film`、`files`、`history`、`export`、`gone`、`ask`/`notice`。 |

版本历史也在项目页可见：`GET history`、`history/files`、`history/poster/:commit`、`POST history/commit|discard|restore|checkout`、`PATCH/DELETE history/branches/:name`、`POST history/merge`。

## 数据与约定

项目就是文件夹：`film.html`、`assets/`、`.film/` 一起移动或复制。`folder` 是影片源地址，不要把它当成本机路径；本机路径是 `project.path`。项目删除、重命名和导出互斥，冲突用 409 说明。
