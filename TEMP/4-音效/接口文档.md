# 音效接口文档

当前界面是音效步骤（SoundStage）：左侧为项目素材、网络素材、AI 生成；中间为画面和试听；右侧为素材/片段检查器；底部是影片音频轨。所有读取以 `film.html` 为准，写入统一走原生编辑操作，不维护第二份时间线。

## 读取

| 接口 | 用途 |
| --- | --- |
| `GET /api/projects/:id/audio` | 当前音频轨、片段、voice/music/sfx/footage 统计。时间字段为毫秒。 |
| `GET /api/projects/:id/audio/library?role=&q=&facts=1` | 项目 `assets/` 下的音频。`role=all|voice|music|sfx`；`facts=0` 跳过 ffprobe。 |
| `GET /api/projects/:id/audio/asset?path=&what=probe|wave|loudness&from=&to=` | 时长/流信息、波形、某段响度。 |
| `GET /api/projects/:id/audio/catalog` | TTS、配乐、音效当前是否有可用 provider；也返回 provider 名称。 |
| `GET /api/projects/:id/audio/voices?q=&language=&gender=&limit=&via=&model=` | TTS 声音列表，复用 `openfilm get voice`；指定 provider/model 时列出对应声音。 |

`GET audio` 的 `revision` 用于 `base`；片段还带 `atMs`、`startMs`、`endMs`、`durationMs`、`speed`、`volume`、`fadeInMs`、`fadeOutMs`、`track`、`muted/locked/hidden`、`missing`。素材的 `source` 为 `local`、`download` 或 `ai`。

## 来源

| 接口 | 用途 |
| --- | --- |
| `GET /api/projects/:id/audio/search?role=&q=&source=all|local|freesound|jamendo&limit=` | 本地、Freesound 音效、Jamendo 配乐。没有 key 时对应 `sources[].available=false`，不报错。 |
| `POST /api/projects/:id/audio/import` | `{ url, role?, name?, source?, meta? }`；只接受公网 http/https，限制 300 MB，写入 `assets/audio/{sfx|music|vo}`。 |
| `POST /api/projects/:id/audio/generate` | TTS：`{ kind:"voice", text, voice }`；配乐/音效：`{ kind:"music"|"sfx", prompt, sec }`。可带 `via`、`model`、`out`。 |

网络结果保留 `downloadUrl`、`previewUrl`、`page`、`credit`、`license`、`tags`；导入后这些信息写入 `.film/audio.json`。Freesound 使用 `FREESOUND_API_KEY`，Jamendo 使用 `JAMENDO_CLIENT_ID`，也可通过 `GET /api/providers` 返回的 `freesound` / `jamendo` 项，用 `PUT /api/providers/:id/key` 写入 `~/.openfilm/providers.json` 的 `keys`。它们只作为搜索 Key，不进入 `use`/`model` 的生成选择。

## 写入

`POST /api/projects/:id/audio/place` 是最常用的插入：

```json
{ "path": "assets/audio/sfx/hit.wav", "at": 3, "start": 0, "end": 1.5,
  "volume": 0.8, "fade": [0.1, 0.2], "speed": 1, "track": 0, "base": "<revision>" }
```

`at`、`start`、`end`、`fade` 都是秒；省略 `end` 时读取文件时长。返回 `clipId` 和编辑后的影片。

`POST /api/projects/:id/audio/ops` 接受**全部原生 `applyOps` 操作**：`insert`、`move`、`set`、`split`、`props`、`fields`、`remove`、`track`、`reorder`、`stage`。请求 `{ base, ops }`，与 `/edit` 完全一致；冲突返回 409 和当前影片。

原生模型没有自动 ducking 字段；当前用 `volume` 和 `fade`。自动避让需要新增原生字段或后期处理，不能伪装成现有操作。

## 与音效相关的既有接口

- `GET/PUT/PATCH/DELETE /api/projects/:id/files`：项目文件列表、上传、移动、删除；音效上传仍走这里。
- `POST /api/projects/:id/files/bring`：从本机复制/链接音频。
- `GET /api/projects/:id/media?what=probe|wave|loudness`：底层媒体事实；音效接口也使用同一实现。
- `POST /api/projects/:id/edit`：编辑器自己的原生编辑路径；音效面板在有编辑回调时直接使用它。
- `GET /api/projects/:id/events`：`film` 和 `files` 事件用于刷新音效页。
- `/api/get`、`/api/providers`：provider 连接、模型和 `openfilm get` 的原始能力。

## Agent

音效页的 AI 对话有独立的 `scope=audio`，使用 `audio` Agent 的 ReAct 工具循环；无可用 Agent/provider 时返回明确错误，不写入修改。

可用工具：

- 读取：`read_project`、`read_timeline`、`read_audio`、`list_audio`、`list_project_files`。
- 检索/分析：`search_audio`（本地/Freesound/Jamendo）、`list_voices`、`probe_audio`、`analyze_audio`。
- 字幕：`read_captions`，以及 `edit_captions` 的 `line` / `style` / `translate` / `transcribe`；字幕写入复用字幕文档，不另建字幕时间线。
- 生成/导入：`generate_audio`（TTS/音乐/音效）、`import_audio`（受控网络导入）。
- 写入：`edit_timeline`（所有原生 `applyOps`）、`undo_timeline`；音频落轨不建立第二套时间线。
- 交互：`ask_user`。

音频 Agent 是独立工作槽，需要在设置中绑定模型；未绑定或 provider 不可用时返回清晰错误。MCP 当前没有音频生成工具，也没有 render/export 工具。
