# 交付接口文档

当前界面：交付步骤（`DeliverStage`）和导出中心。交付页只展示出口，真正排队、进度和文件位置由导出中心负责；最终渲染/导出只能由用户触发。

## 后端模块

`exports.mjs`（视频、GIF、音频、图片、字幕、幻灯片、NLE、项目包）、`encoders.mjs`、`shared.mjs`、`nle.mjs`、`jianying.mjs`、`slides.mjs`、`captions.mjs`、`zip.mjs`、`locations.mjs`。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/projects/:id/exports` | 当前任务、默认导出目录、本机编码能力、草稿应用、字幕数量、项目各部分大小。 |
| `POST /api/projects/:id/exports` | 一个 `ExportAsk`，或 `{ jobs: ExportAsk[], folder? }` 一次排多个；返回 `{ export }` 或 `{ exports }`。 |
| `DELETE /api/projects/:id/exports/:jobId` | 取消排队/运行中的任务。 |
| `POST /api/projects/:id/exports/:jobId/reveal`、`/open` | 在文件管理器中显示或打开第一个产物。 |
| `GET /api/projects/:id/events` | `{ type:'export', job }` 进度与状态。 |
| `GET /api/projects/:id` | 影片、`rev`、`value`、`doc`；交付页据此判断是否为空片。 |

## 导出类型

`kind` 可为 `video`、`gif`、`audio`、`stills`、`poster`、`subtitles`、`slides`、`nle`、`project`。视频支持 `codec`、画幅、分辨率、fps、质量、音频、烧字幕、区间、透明度；音频支持 `mix` 和分轨 `stems`；`project` 支持 `as: zip|folder` 与 `parts: history|chat|logs`。完整字段由 `exports.mjs` 的 `ExportAsk` 定义。

## 约定

导出是唯一产生最终文件的操作；Agent/MCP 没有 render/export 工具。缺媒体、空片、无字幕、无音轨等前置条件由后端拒绝并给出原因。输出目录不会覆盖旧文件；`job` 的 `status` 和 `progress` 是前端唯一可信进度源。
