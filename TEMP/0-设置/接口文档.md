# 设置接口文档

当前界面：SettingsModal，含通用、Providers、Agents、Skills、快捷键、存储、开发者、关于。设置不改 `film.html`，只改 Studio 自己的配置或服务连接。

## 后端模块

`server.mjs`（路由与鉴权）、`prefs.mjs`、`providers/index.mjs`、`provider-cards.mjs`、`agent-cards.mjs`、`keys.mjs`、`projects.mjs`、`skills.mjs`、`client.mjs`、`diagnostics.mjs`。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET/PATCH /api/prefs` | 本机偏好：代理、已看版本、项目目录、快捷键、粗剪候选数。 |
| `GET /api/providers` | 旧式 provider 列表、连接状态和当前 `use`/`model`。Freesound、Jamendo 作为仅搜索 Key 出现，不参与生成选择。 |
| `PUT/DELETE /api/providers/:id/key` | 保存/移除 provider Key。`PUT { env:true }` 使用环境变量。 |
| `PUT /api/providers/use` | 选择某类媒体由哪个 provider/模型生成。 |
| `POST /api/providers/:id/billing` | 打开 provider 的余额页面。 |
| `GET/PUT /api/provider-cards` | 统一 provider card 状态；返回时连接 Key 已脱敏。 |
| `POST /api/provider-cards/test` | 测试卡片连接，返回 `{ ok, elapsedMs, detail }`。 |
| `GET/PUT /api/agent-cards` | 七个 Agent 工作槽（planner / storyboard / material / edit / audio / qc / conversation）的启用、模型、提示词和采样参数。 |
| `GET /api/skills?project=` | 项目/个人/官方 Skill 列表；`POST /skills/import` 导入文件夹。 |
| `PUT/DELETE /api/skills/:name/*` | 安装、启停、封面、删除（只允许自己的 Skill 改封面）。 |
| `GET /api/version?check=1`；`POST /api/update` | 当前版本/最新版本；后台升级 Studio。 |
| `GET /api/doctor`；`GET /api/diagnostics/problems`；`POST /api/diagnostics/export` | 诊断报告、近期问题、导出诊断包。 |
| `GET /api/locations`；`PUT /api/locations/projects`；`POST /api/locations/projects` | 项目库位置、迁移、在文件管理器中打开。 |
| `GET/DELETE /api/api-logs`；`GET/DELETE /api/model-logs` | 开发者的请求/模型调用日志。 |
| `POST /api/desktop` | 打开桌面安装包或下载页。 |

## 数据与约定

偏好保存在 `~/.openfilm/prefs.json`；provider Key 在 `~/.openfilm/providers.json`，卡片在 `provider-cards.json`，Agent 在 `agent-cards.json`。除 `GET /api/version`、`/api/health` 等公开项外，所有接口沿用 Studio 的 key/cookie 鉴权；写请求必须来自 Studio 自身 origin。

`GET /api/providers` 的 Freesound/Jamendo 项 `verbs` 为空，只用于 `PUT /key` 写入 `keys.freesound`、`keys.jamendo`，供音效网络搜索使用。
