# Skill 接入设计

> 本文定义 AI 剪辑 Agent 的 Skill 体系：不接知识库，用 Skill 承载规则、模板、风格、案例、术语和操作方法。Skill 数量不限、类型不限，按阶段装配，渐进加载，权限可控。
>
> 配套图：`Skill接入图.drawio`。

---

## 一、Skill 与素材库的分工

| 层 | 存什么 | 回答什么问题 | 是否直接上时间线 |
| --- | --- | --- | --- |
| 向量素材库 | 时间片段、画面、声音、元数据 | “哪一段画面能用在第 3 镜？” | 是 |
| Skill | 规则、模板、风格、术语、案例、操作配方 | “第 3 镜应该怎么剪？按什么规范？” | 否 |

素材库决定“用什么画面”，Skill 决定“按什么方法剪”。

---

## 二、Skill 体系结构

```text
Skill 注册表
  → Skill 路由 / 激活
  → 渐进加载
  → 权限校验
  → 注入到对应 Agent
  → 产出与反馈
```

### 2.1 Skill 注册表

每个 Skill 登记：

- 标识、名称、版本、来源；
- 类型：品牌、平台、叙事、镜头、剪辑、字幕、配乐、合规、项目风格等；
- 适用阶段；
- 触发条件；
- 所需输入、可产出内容；
- 权限：可读文件、可调用工具、是否含脚本；
- 资源：模板、示例、术语表、规则表、参考图、LUT、字幕样式；
- 兼容格式。

**数量不限、类型不限**靠注册表 + 适配器，不把所有内容写进主流程。

### 2.2 Skill 路由 / 激活

激活方式：

1. 用户显式点名；
2. 当前阶段默认启用；
3. 根据 brief/镜头意图匹配触发条件；
4. 项目级 Skill 锁定。

优先级：

```text
项目 Skill > 用户 Skill > 官方 Skill > 内置默认
```

同一能力冲突时，显式点名优先；仍冲突则记录并提示。

### 2.3 渐进加载

- 先读元数据：名称、描述、适用阶段、权限；
- 命中后再读完整说明；
- 需要时再加载资源（模板、术语、规则表、示例、脚本）；
- 不把整包 Skill 一次性塞进上下文。

### 2.4 权限与安全

- Skill 只能访问声明过的资源；
- 含脚本的 Skill 默认不执行，需显式授权；
- Skill 不能直接改项目文件；
- Skill 版本按项目锁定，保证可复现；
- 导入时展示权限、来源和资源清单。

## 三、在哪些阶段接入什么 Skill

> 下表是接入点示例，不是 Skill 类型的上限。

| 阶段 | 接入的 Skill | 为什么 | 产出 |
| --- | --- | --- | --- |
| 0 项目初始化 | 平台规格 Skill、品牌 Skill、项目模板 Skill | 先确定画幅、时长、平台限制、品牌禁用项 | 项目约束、已激活 Skill 清单 |
| 0.5 Skill 装配 | 按阶段和意图选择 Skill | 让后续 Agent 拿到正确的方法和规则 | SkillContext、权限、版本锁 |
| 1 分镜规划（输入解析 + 分镜 + 预检） | 品牌/产品 Skill、受众与风格 Skill、历史项目 Skill、叙事结构 Skill、镜头语言 Skill、类型模板 Skill、案例 Skill、素材分类 Skill、同义词/别名 Skill、版权 Skill | 解析输入、生成分镜、构造短词组查询、预检覆盖、发现缺口 | Brief、术语表、分镜、MaterialPlan、CoverageReport |
| 审批门 1 分镜审批 | 项目决策 Skill、锁定规则 Skill | 让审批依据和后续锁定一致 | 审批记录、锁定项 |
| 2 素材检索 | 素材标签 Skill、同义词 Skill、禁用词 Skill、授权 Skill | 扩大召回、避免错误素材、保证可用 | 查询、候选、过滤理由 |
| 3 粗剪 | 剪辑语法 Skill、节奏 Skill、转场 Skill、品牌风格 Skill | 决定镜头长度、顺序、转场和节奏 | EDL、剪辑理由 |
| 4 精剪/音频/字幕 | 发音 Skill、品牌术语 Skill、字幕规范 Skill、配乐情绪 Skill、响度 Skill | 读对品牌名、字幕合规、音乐不压旁白 | 旁白、配乐、字幕、混音参数 |
| 5 草稿/质检 | 平台规范 Skill、广告合规 Skill、品牌 VI Skill、可访问性 Skill | 自动检查违规、品牌错误、字幕可读性 | 质检报告、修复建议 |
| 审批门 2 成片审批 | 项目决策 Skill、锁定规则 Skill | 让最终审批和锁定依据一致 | 审批记录、锁定项 |
| 6 最终渲染 | 输出规格 Skill、平台导出 Skill | 按最终规格渲染和导出 | MP4、工程快照 |
| 7 交付 | 交付规范 Skill、命名 Skill | 命名、归档、清单一致 | 交付清单、归档记录 |
| 8 对话剪辑 | 项目决策 Skill、锁定规则 Skill、历史修改 Skill、风格 Skill | 后续修改不偏离已批准方向 | 修改操作、依据 |
| Skill 导入 | 技能说明、模板、规则、示例 | 新能力通过 Skill 扩展，不改主流程 | Skill 包、权限声明、版本锁 |

## 四、Skill 类型示例

不设类型上限，常见类型包括：

- 品牌：品牌语气、禁用表达、VI、Logo 使用；
- 平台：画幅、时长、标题、字幕、审核规则；
- 叙事：三幕、起承转合、钩子、反转；
- 镜头：景别、机位、运动、构图；
- 剪辑：节奏、转场、J-cut/L-cut、镜头长度；
- 音频：发音、语气、配乐情绪、ducking、响度；
- 字幕：断句、行长、安全区、双语、逐词高亮；
- 合规：广告法、版权、平台审核；
- 项目：项目决策、锁定项、历史修改、风格指南；
- 案例：优秀广告、参考片、历史成片。

## 五、为什么用 Skill 替代知识库

1. **规则不是检索出来的**：剪辑规范、品牌语气、平台限制是“方法”，需要按阶段注入，不是每次相似度搜索。
2. **Skill 可以带资源**：模板、术语表、规则表、示例、LUT、字幕样式都可以随 Skill 走。
3. **渐进加载更省上下文**：先读元数据，命中再读正文和资源，不把整包塞进提示词。
4. **权限边界清楚**：Skill 可声明可访问资源、可调用工具、是否含脚本。
5. **数量不限靠注册表**：新增 Skill 只需导入和授权，不改主流程。

## 七、失败与降级

1. Skill 不存在：使用内置默认；
2. 权限不足：改用项目级 Skill 或请求授权；
3. Skill 冲突：显式点名优先，其次项目 > 用户 > 官方；
4. 脚本不可信：不执行，只使用说明和资源；
5. 仍无合适 Skill：记录缺口，交给人或后续补充。

Skill 失败不能阻断素材检索；但涉及品牌、合规、平台硬约束时，必须显式告警。

---

## 八、验收标准

- 新增 Skill 只需导入和授权，不改主流程；
- 每个阶段能拿到对应 Skill；
- Skill 支持多种格式；
- Skill 渐进加载、权限、版本锁可用；
- Skill 冲突有优先级；
- Skill 能影响分镜、检索、剪辑、字幕、配乐、质检；
- 对话剪辑能读取项目决策和锁定 Skill。
