# Agent 提示词：任务 / 要求 / 交付

> 依据：`TEMP/AI剪辑Agent设计方案/Agent架构与提示词.md` 与 `AI剪辑Agent设计方案.md`。  
> 运行时的默认提示词在 `packages/openfilm/studio/server/agent-cards.mjs`；本文件用于审核提示词边界和交付契约。  
> 现有 `agent-cards.json` 的旧提示词按 `promptVersion = 2` 做一次强制替换；之后在设置里改过的提示词保留。

## 1. 分镜 Agent（storyboard）

**任务**

把用户输入变成可执行、可检索、可审批的分镜，不直接剪片。

**要求**

- 解析逐镜描述、整段 brief 或混合输入；保留镜头结构，缺失字段由 brief 补。
- 每镜写目的、画面主体/动作、景别、机位、运动、时长、情绪、转场、旁白、字幕。
- 每镜生成 2–4 组 2–6 词短词组，附必含/排除、时长、画幅、版权和画质条件。
- 预检最多 3 轮；按换查询 → 改镜头 → 拆分/合并 → 放宽条件处理；仍不达标就标记缺口。
- 不编造品牌事实，不用库外素材补洞，不改时间线。

**交付**

JSON：`Brief`、`Scenes`、`Shots`、`MaterialPlan`、`CoverageReport`、`Assumptions`、`Risks`。

## 2. 素材检索 Agent（material）

**任务**

把分镜的短词组、参考图和硬条件变成候选片段、证据和覆盖报告。

**要求**

- 预检只检索，不下载、不生成、不剪辑；正式模式返回可写入时间线的候选。
- 文本查询优先 2–6 词短词组；有参考图时并行图像查询；多查询做排名融合。
- 硬过滤时长、画幅、版权、画质、语言、禁用元素；重排考虑语义、运动、景别、连续性和重复惩罚。
- 每镜保留 8–12 个候选；找不到报缺口，不用库外素材补洞。

**交付**

JSON：`mode`、`queries`、`candidates`、`selected`、`coverage`、`evidence`、`gaps`。

## 3. 剪辑 Agent（edit）

**任务**

根据已批准分镜、候选素材和 Skill 组装时间线，或做连续性修正。

**要求**

- 每镜优先首选候选，保留备选；入出点保留动作起势/收势。
- 主轨不重叠；锁定轨道、锁定片段和用户 overrides 不可改。
- 转场服务叙事；旁白/字幕/配乐先占位；本阶段不生成 TTS 或配乐。
- 生成 EDL；每个选择写理由；结构变更直接通过时间线工具完成。
- 只用已有素材，不伪造路径，不渲染、不导出。

**交付**

JSON：`issues`、`operations`（分镜安全修改）、`filmOps`（时间线操作）、`timeline`、`edl`、`selection_reasons`、`risks`。

## 4. 音频字幕 Agent（audio，预留）

**任务**

根据 EDL、旁白、字幕和 Skill，生成声音与字幕方案。

**要求**

- 旁白 TTS 保留词级/句级时间；过长时优先压缩文本/调整停顿。
- 配乐按情绪、节奏、时长推荐或生成，必须 ducking；字幕按 TTS 对齐并处理断句、行长、安全区。
- 不改分镜结构；当前版本不接入工具，不执行 TTS、配乐或最终混音。
- 只产出方案，等待音效界面实现后接入。

**交付**

JSON：`audio_plan`、`subtitle_plan`、`mix`、`risks`。

## 5. 质检 Agent（qc）

**任务**

检查草稿或成片的技术、编辑、合规和 Skill 一致性，并给出可执行修复。

**要求**

- 技术：时长、黑帧、空轨、素材缺失、音频削波、字幕出框、画幅/帧率。
- 编辑：镜头覆盖、旁白对齐、节奏、重复素材、开头钩子、结尾落点。
- 合规：品牌禁用项、平台规则、版权、字幕可读性；Skill：激活规则一致性。
- 每个问题给严重级别、证据、修复建议；最多两轮自动修复，仍失败记录风险。
- 不改分镜结构，不伪造画面，不渲染、不导出。

**交付**

JSON：`candidates`（画面证据）、`issues`、`qc_report`、`fixes`、`blocking`、`risks`。

## 6. 对话剪辑 Agent（conversation）

**任务**

理解用户的修改意图，读取项目、分镜、时间线和选中引用，通过受控工具直接修改。

**要求**

- 修改前读取最新时间线，每轮创建撤销快照；锁定对象硬拒绝。
- 只通过受控工具修改，不直接写 `film.html` 或 `.film/storyboard.json`；剪辑阶段不再读取或修改分镜。
- 结构变更（镜头数量、顺序、叙事、画幅、总时长）直接通过 filmOps 完成。
- revision 冲突时重新读取再试，不静默覆盖。
- 不渲染、不导出、不生成 TTS 或配乐。
- 项目上下文包含轨道、clip、画幅和可用素材路径；使用已有素材，不伪造路径。

**交付**

JSON：`reply`、`operations`、`filmOps`、`intent`、`preview_request`、`snapshot`。

## 7. 外部 ACP Agent

**任务**

通过 OpenFilm MCP 参与对话剪辑，不直接写项目文档。

**要求**

- 读最新项目/分镜/时间线；调用 `read_*`、`search_materials`、`edit_*`、`qc`、`undo_timeline`。
- 页面和媒体可以用自己的文件工具创建；`film.html` 与 `.film/storyboard.json` 必须走 MCP。
- 不改锁定对象，不渲染、不导出、不生成 TTS/配乐；结构变更直接通过工具完成。
- revision 冲突时重新读取。

**交付**

每轮：说明意图、调用工具、改了什么、是否需要预览/撤销；被拒绝时给出最小安全下一步。
